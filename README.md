# 🌙 Mary's Universe

> A personal portfolio where creativity, code, research, and storytelling come together.

**Mary's Universe** is an interactive personal portfolio designed as a digital galaxy. Each section represents a different part of my journey, while projects are presented as constellations waiting to be explored.

🔗 **Live Portfolio:**  
https://thedatapoetmaryam.github.io/Portfolio/

💻 **GitHub Repository:**  
https://github.com/TheDataPoetMaryam/Portfolio

---

## ✨ About the Project

Mary's Universe is more than a traditional portfolio website.

It was designed to create an immersive experience where:

- ⭐ Projects become constellations
- 🌙 Sections become parts of a larger universe
- 🚀 The Journey section represents personal and professional growth
- 🔬 Research work is presented as part of the exploration
- 🎨 Design and technology come together to create a unique visual identity

The goal was to build a portfolio that feels personal, interactive, and memorable while still presenting my work in a professional way.

## 🎨 Design Philosophy

The visual identity of Mary's Universe is inspired by:

- 🌌 Deep-space environments
- ✨ Stars and constellations
- 🌙 Moon phases
- 💜 Purple cosmic tones
- 🟡 Gold celestial accents
- 🔮 Interactive exploration

The design was created to balance visual storytelling with usability across desktop and mobile devices.

---

## 📱 Responsive Design

The portfolio was designed to work across different screen sizes, including:

- 💻 Desktop
- 📱 Mobile
- 📲 Landscape mobile layouts

Interactive sections were adapted for touch-based interaction where required.
